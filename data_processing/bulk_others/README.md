# Published bulk datasets — the Figure 2 ground truth

Bulk reference data for GM12878 and IMR90, and the differential-methylation calling
run on it. These define the ground truth the single-cell mixture is scored against.

Everything here is **published third-party data** (ENCODE) plus the GM12878 bulk
already processed for Figure 1 — nothing is generated by this paper.

## Run order

### 01_download

- **`01_setup_bulk_links.sh`** — creates `data/bulk/{GM12878,IMR90}/{hic,atac,methylation}`
  and symlinks the GM12878 bulk data already prepared under `../../main_figures/fig1`.
- **`02_download_imr90.sh`** — fetches IMR90 from ENCODE: WGBS `ENCFF591PKF.bigBed`
  and ATAC `ENCFF770EAV.bigWig`. Resumable (`wget -c`).

### 02_process

- **`01_methylation_process_imr90.sh`** — IMR90 WGBS bigBed → BED → HCG subset →
  bigWig (all-CpG and HCG). Mirrors the Figure 1 bulk methylation processing so the
  two cell lines are treated identically. Produces the per-sample HCG methylation
  the DMR caller consumes.
- **`02_bin_bulk_atac_250kb.py`** — bins the bulk ATAC signal bigWigs to 250 kb mean
  signal via pyBigWig → `bulk_atac_250kb.tsv`. This is the bulk reference for the
  accessibility panel.
- **`03_build_bulk_methylation_bins.py`** — bins bulk WGBS methylation onto the *same
  bin grid as the single-cell matrices*, giving the GM12878 and IMR90 references the
  UMAP notebook correlates each cluster against to call cell types.

  ```bash
  python 03_build_bulk_methylation_bins.py          # 250 kb, what the UMAP reads
  ```

  Reads ENCODE-style bulk WGBS BEDs (`bigBedToBed` output, the same conversion step
  `01_methylation_process_imr90.sh` performs) plus `bins_{label}.tsv` from
  `../../mixture_cellline/02_qc/build_methylation_matrices.sh` — so **run that
  first**, otherwise the bins grid does not exist and the script says so.

  At 250 kb the outputs keep their historical un-suffixed names
  (`bulk_methylation_GM12878.txt.gz`), which is what the notebook reads; other bin
  sizes get a `_{label}` suffix.

  Note this is a *different, earlier* bulk lineage from the ENCODE files downloaded in
  `01_download/`: GM12878 here comes from `GSM2308632` / `GSM2308633`, not
  `ENCFF529CNU`. The two are used by different figures and are not interchangeable.

### 03_differential

- **`01_run_metilene_dmr.sh`** — de-novo differentially methylated regions, GM12878
  vs IMR90, on the bulk HCG WGBS, via **metilene**. Per-sample bedgraphs →
  `metilene_input.pl` (bedtools unionbedg) → `metilene -f1 -c2 -M300 -m10 -d0.1
  -X1 -Y1` → `metilene_output.pl`. **213,578 raw / 76,126 significant DMRs**;
  `meandiff` is GM − IMR.

The DMRs are the regions the single-cell pseudobulk is compared over — see
`../mixture_cellline/03_pseudobulk/02_build_sc_pseudobulk_metilene_dmr.sh`.

## Why differential calling lives in processing, not with the figures

It runs on bulk data only, never touching a single cell, and it *produces* the
region sets that the single-cell pseudobulk builders consume. Putting it with the
figures would make processing depend on the figure folder.

## Outputs

| Product | Path |
|---|---|
| IMR90 bulk methylation tracks | `data/bulk/IMR90/methylation/*.{bed,bw}` |
| Bulk ATAC binned to 250 kb | `analysis/gch_acc_250kb/bulk_atac_250kb.tsv` |

| Bulk methylation references | `bulk_methylation_{GM12878,IMR90}.txt.gz` (250 kb bins) |

## Not included

- **`fix_gm_bed_links.sh`** — added per-CpG BED symlinks needed by methylKit; the
  methylKit branch is not on the published path.
- **`dmr_methylkit_250kb.R/.sh`** — differential 250 kb tiles via methylKit. A
  parallel approach to the same question, feeding a methylation heatmap that is not
  a published panel. The published figure uses the metilene DMRs above.
- **`diffbind_atac.R/.sh`** and **`download_atac_bams.sh`** — differential ATAC peaks
  via DiffBind/DESeq2. The published accessibility panel ranks bins by bulk ATAC
  *signal* difference rather than by DiffBind peaks, so this is off-path.
- **`copy_imr90_hic.sh`** — copies the IMR90 in-situ Hi-C (`ENCFF188SSH`, 17.5 GB)
  off scratch. Belongs with the APA analysis, still to be migrated.
