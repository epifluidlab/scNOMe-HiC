# Published bulk datasets — the Figure 2 ground truth

Bulk reference data for GM12878 and IMR90, and the differential calling run on it.
All third-party (ENCODE, GEO) plus the GM12878 bulk already processed for Figure 1 —
nothing here is generated by this paper.

## Run order

| Step | What it is |
|---|---|
| `01_download/01_setup_bulk_links.sh` | Creates `data/bulk/{GM12878,IMR90}/{hic,atac,methylation}` and symlinks the GM12878 bulk prepared for Figure 1. |
| `01_download/02_download_imr90.sh` | Fetches IMR90 from ENCODE: WGBS `ENCFF591PKF.bigBed`, ATAC `ENCFF770EAV.bigWig`. Resumable. |
| `02_process/01_methylation_process_imr90.sh` | IMR90 WGBS bigBed → BED → HCG subset → bigWig. Mirrors the Figure 1 bulk processing so both cell lines are treated identically. |
| `02_process/02_bin_bulk_atac_250kb.py` | Bins the bulk ATAC bigWigs to 250 kb mean signal → `bulk_atac_250kb.tsv`. |
| `02_process/03_build_bulk_methylation_bins.py` | Bins bulk WGBS onto the same grid as the single-cell matrices → `bulk_methylation_{GM12878,IMR90}.txt.gz`. Needs `bins_{label}.tsv` from `../mixture_cellline/02_qc/build_methylation_matrices.sh`, so **run that first**. |
| `03_differential/01_run_metilene_dmr.sh` | De-novo DMRs, GM12878 vs IMR90, on bulk HCG WGBS. `metilene -f1 -c2 -M300 -m10 -d0.1 -X1 -Y1`. 213,578 raw / 76,126 significant; `meandiff` is GM − IMR. |
| `04_hic_loops/01_subsample_gm_insitu.sbatch` → `subsample_hic.py` | Pixel-level `Binomial(count, p=0.307)` subsample of GM in-situ Hi-C at 5 kb, rebuilt with `juicer pre`. |
| `04_hic_loops/02_hiccups_gm_subsampled.sbatch` | GPU HICCUPS on the depth-matched GM `.hic` at 25 kb. |
| `04_hic_loops/03_hiccups_imr_full.sbatch` | GPU HICCUPS on full-depth IMR90 at 25 kb. |
| `04_hic_loops/04_hiccupsdiff.sbatch` | juicer HiCCUPSDiff on the two `.hic` files: per-loop contact-frequency test with FDR → `{GM12878,IMR90}_specific_hiccupsdiff.bedpe` (516 / 968). |
| `04_hic_loops/05_apa_pileup_insitu.sbatch` → `05_apa_pileup_insitu.py` | APA pile-up of those loop sets against the single-cell pseudobulk `.Q.cool`, over all 22 autosomes. Caches `apa_insituHCD.npz` for the Figure 2 panel. |
| `05_hic_loglog/01…04` | HOMER contact-frequency-vs-distance tables for bulk NOMe-HiC, pseudobulk NOMe-HiC and ENCODE in-situ Hi-C → the `*.petag.FreqDistribution_1000.txt` that Figure S1's log-log panel plots. |

| Product | Path |

| IMR90 bulk methylation tracks | `data/bulk/IMR90/methylation/*.{bed,bw}` |

## Notes

- The DMRs are the regions the single-cell pseudobulk is compared over — see
  `../mixture_cellline/03_pseudobulk/02_build_sc_pseudobulk_metilene_dmr.sh`.
  Differential calling lives here because it runs on bulk only and produces the
  region sets the single-cell builders consume.
- `03_build_bulk_methylation_bins.py` uses a **different, earlier** GM12878 lineage
  (`GSM2308632` / `GSM2308633`) from the ENCODE files in `01_download/`
  (`ENCFF529CNU`). Different figures use them; they are not interchangeable. At
  250 kb the outputs keep their un-suffixed names; other bin sizes get a `_{label}`
  suffix.
- Loops are called on **ENCODE in-situ Hi-C**, not on NOMe-HiC — NOMe-HiC has too few
  contacts for HICCUPS. GM in-situ is 3.26× deeper than IMR90 (chr1 250 kb sums
  309.8 M vs 95.0 M), so GM is subsampled to match first; otherwise loop counts would
  track depth rather than biology. Subsampling is pixel-level because only the
  processed `.hic` survives, not the raw pairs.
