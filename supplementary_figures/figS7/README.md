# Supplementary Figure S7 — QC / batch diagnostics on the integrated UMAP

Mouse cortex, 1,577 cells. Panels drawn on the joint three-modality embedding,
showing that the biological-replicate split is removed by Harmony and that no
per-cell QC measure structures the embedding.

## Inputs

All from `../../data_processing/mouse_cortex/subset_clustering/250kb_denovo/`:

- `tables/{hcg,hic,gch}_svd_raw.txt` — pre-Harmony SVDs
- `tables/joint_umap.txt` — the Harmony-corrected joint layout
- `annotation/metadata_with_cell_type.txt` — 1,577 cells × 32 fields. Panels C–G read
  `library_prep_date`, `mapq30num`, `mapq30rate`, `noncpg_chrM`, `cisnum`, `transnum`.

## Notes

- §3 recomputes the uncorrected embedding from the SVD tables every time, and is
  deterministic — two independent recomputes agree to 0.000e+00. The layout
  previously on disk (`joint_umap_uncorrected.txt`, 2026-08-11) could not be
  regenerated by any code path and was retired; it is kept in
  `250kb_denovo/archive_superseded/*aug11_session_artifact*`. Neither layout is more
  faithful to the data (neighbourhood preservation 0.464 vs 0.466).
- The cause was `write.table`'s 15-significant-digit round-trip: read back, the SVD
  differs by ~5e-15, which `umap()` amplifies into a visibly different layout.
  Clustering is unaffected at that scale.
